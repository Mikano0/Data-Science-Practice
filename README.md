# Data Analysis Practice Projects

This repository contains beginner-friendly data analysis projects created while learning Python with Angela Yu's course. Each project focuses on cleaning, exploring, and visualizing data with Python libraries like pandas and matplotlib

---

## Projects

### 1. Google Play Store Analysis
- Explored app data from Google Play Store
- Cleaned data with pandas
- Visualized top categories, ratings, and reviews

### 2. Google Trends Analysis
- Analyzed search trends over time
- Created visualizations for trending topics
- Practiced working with time series data

### 3. LEGO Sets Analysis
- Investigated LEGO sets by theme
- Counted number of sets and pieces per theme
- Visualized trends and patterns in LEGO releases

---

## Tools Used
- Python
- pandas
- matplotlib
- Jupyter / Google Colab
