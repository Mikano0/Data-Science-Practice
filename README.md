Data Analysis Practice Projects

This repository contains beginner-friendly data analysis projects created while learning Python with Angela Yu's course. Each project focuses on cleaning, exploring, and visualizing data using Python libraries like pandas, matplotlib, seaborn, and numpy.

Projects
1. Google Play Store Analysis

- Explored app data from the Google Play Store
- Cleaned messy data using pandas
- Visualized top categories, ratings, installs, and reviews
- Practiced handling missing values and data type conversion

2. Google Trends Analysis

- Analyzed search trends over time
- Worked with time series data
- Created line charts to compare multiple trends
- Practiced grouping and filtering data

3. LEGO Sets Analysis

- Investigated LEGO sets by theme
- Counted number of sets and pieces per theme
- Explored trends in LEGO releases over time
- Visualized patterns using bar charts and line plots
4. Seaborn & Linear Regression Analysis

- Used seaborn to create advanced statistical visualizations
- Built regression plots to explore relationships between variables
- Learned about correlation and trend lines
- Compared scatter plots with regression models
- Practiced interpreting slope and strength of relationships

5. NumPy Calculations Project

- Performed numerical computations using NumPy
- Practiced working with arrays and matrix operations
- Calculated mean, median, standard deviation, and other statistics
- Learned about vectorized operations for faster calculations
- Compared NumPy performance with standard Python lists
